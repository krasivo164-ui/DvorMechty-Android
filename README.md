# Двор мечты — Android 1.17.1

Мобильная игра о восстановлении двора, общении с жителями и объединении предметов. В этой Android-версии используется автономный HTML5-клиент 1.17.1 с графикой, героями и игровой логикой; его ресурсы встроены в `app/src/main/assets/index.html`.

## APK

Вкладка [Actions](../../actions) → **Android APK** → **Run workflow**. Сборка также запускается при изменениях ветки `main`. После успешной сборки скачайте файл из раздела **Artifacts** (`DvorMechty-debug-APK`).

Это отладочный APK с автоматически созданной подписью. Для выпуска в магазине понадобится отдельная постоянная подпись.

**Приложение:** `ru.dvormechty`. **Версия:** 1.17.1. **Минимальный Android:** 6.0.

**Сохранения:** хранятся в WebView на телефоне. Перед удалением прежней версии рекомендуется экспортировать резервную копию в игре.

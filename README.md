# Город Пульс 3D — интерактивный прототип v0.1.0

**Ветка:** `city-pulse-3d`. Старый «Двор мечты» сохранён в `main`.

Полностью автономная стилизованная 3D-игра WebGL в оболочке Android WebView.
7 движущихся жителей, анимированные машины и кошки, городские улицы, здания, парк и фонтан.
Управление персонажем (сенсорный джойстик, тап по карте, WASD), 6 заданий, диалоги, восстановление города,
развитие уровня и монеты, день/ночь, сохранения.

**Сборка:** GitHub Actions → Gorod Puls 3D APK, в артефактах `GorodPuls-3D-debug-APK`.

**Важно:** это вертикальный срез, а не готовая AAA-игра. Требуются реальный тест на Android,
дальнейшие 3D-модели и анимации, звуки, контент и тестирование удержания игроков.
